# Visualizations

This folder contains the charts generated during the EDA phase of this project. Each chart is built using SQL queries (run through Python) and plotted with Matplotlib.

| File | What it shows |
|---|---|
| `q1_pricing_by_subcategory.png` | Median selling price vs average MRP across subcategories |
| `q2_brand_subcategory_heatmap.png` | Which brands are strongest in which subcategories |
| `q4_discounts_inflation.png` | Average discount % vs how often prices are inflated before discounting |
| `q5_low_stock_high_demand.png` | Top 20 high-demand products that are critically low on stock |
| `q6_demand_vs_assortment.png` | Brand-level demand compared against how many products each brand has |
| `q7_sku_priority_score.png` | Top 20 products ranked by a combined priority score (demand + stock urgency + value) |
